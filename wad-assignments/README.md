# WAD Assignments

Meridian Travels website, built step by step.

| Folder | Topic |
|---|---|
| assignment-5 | CSS basics, variables, navbar + hero |
| assignment-6 | Tables, cards, forms, footer, theme, smooth scroll |
| assignment-7 | Flexbox + CSS Grid |
| assignment-8 | Responsive design (media queries) |
| assignment-9 | Client-side validation |

## Publish to GitHub (run in this folder, one commit per assignment)

```
git init
git branch -M main

git add assignment-5 README.md index.html
git commit -m "Assignment 5: link styles.css, CSS variables, styled navbar and gradient hero"

git add assignment-6
git commit -m "Assignment 6: style tables, cards, forms, footer; dark-blue + gold theme; smooth scroll"

git add assignment-7
git commit -m "Assignment 7: flexbox navbar, grid booking form + summary side-by-side"

git add assignment-8
git commit -m "Assignment 8: media queries for tablet/mobile, scrollable tables"

git add assignment-9
git commit -m "Assignment 9: client-side form validation with error messages"

git remote add origin https://github.com/<your-username>/wad-assignments.git
git push -u origin main
```
